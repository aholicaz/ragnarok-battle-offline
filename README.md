# Ragnarok Battle Offline — สร้างใหม่ด้วย Godot

เกม 2D side-scrolling RPG ธีมโลกที่เต็มไปด้วยปีศาจ (โพริง, บาโฟเมต และอื่น ๆ)
พัฒนาด้วย **Godot 4.7** (GL Compatibility · 1280x720)

## เล่นบนเว็บ
เวอร์ชันเว็บถูกสร้างอัตโนมัติทุกครั้งที่ push แล้วขึ้นที่ **GitHub Pages**
(ดูลิงก์ที่แท็บ Actions → build-web → deploy)

- **คอม:** WASD เดิน/กระโดด · J หรือคลิกซ้าย = โจมตี · คลิกขวา = สกิลช่อง 1 ·
  F คุย/เก็บของ · Q ยาเลือด · R ยามานา · 1-4 สกิล · C สเตตัส · I กระเป๋า ·
  E สวมใส่ · K สกิล · V การ์ด · U เควส · Tab เมนู
- **มือถือ/แท็บเล็ต:** ปุ่มบนจอโผล่เองอัตโนมัติ (กดพร้อมกันหลายนิ้วได้)
  เปิด/ปิดได้ที่ เมนูระบบ (Tab) → ปุ่มจอสัมผัส

## ระบบในเกม
สเตตัสแบบ RO · Base/Job Level แยกกัน · อาชีพนักดาบ + ผังสกิล · ตีบวกอุปกรณ์ ·
การ์ดมอนสเตอร์ + อัลบั้ม · เควส · ร้านค้า · เซฟ 3 ช่อง · บอส MVP ·
กล่องสนทนาแบบมีรูปตัวละคร

## โครงโปรเจกต์
```
Sprites/     ไฟล์ภาพทั้งหมด (+ portraits/ = รูปตัวละครในกล่องสนทนา)
data/        ข้อมูลเกมแบบ .tres (มอน · ไอเทม · การ์ด · สกิล · เควส · อาชีพ)
scenes/      ฉากต่าง ๆ (แมพ · ผู้เล่น · มอน · NPC)
scripts/     โค้ดทั้งหมด (core · entities · resources · ui · world)
คู่มือติดตั้ง.md   คู่มือระบบทั้งหมดแบบละเอียด (ภาษาไทย)
```

เพิ่มมอน/ไอเทม/สกิลใหม่ = สร้างไฟล์ `.tres` ใหม่ ไม่ต้องเขียนโค้ดเพิ่ม
